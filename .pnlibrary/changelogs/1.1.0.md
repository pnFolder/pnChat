# pnChat 1.1.0

Paper 1.21+. Нужен Java 21. После замены JAR нужен полный перезапуск сервера.

## Главное

**1. Отдельный плагин pnLibrary.** Библиотека больше не вшита в JAR: pnChat сам скачает и установит плагин pnLibrary при первом запуске (нужен доступ к GitHub). Чат, команды, права и настройки не изменились.

**2. Обновления через pnLibrary.** Проверка и уведомления администраторам (право `pnchat.admin` или `pnlibrary.updates.notify`) теперь выполняются самим pnLibrary, команды `/pn update`. Автозагрузка выключена.

**3. Метрики и диагностика.** Статистика bStats и отчёт для поддержки подключены через pnLibrary.

**4. Права.** У всех прав pnChat появились описания в plugin.yml.
